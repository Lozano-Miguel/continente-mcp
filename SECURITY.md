# Security policy

Continente MCP handles account credentials and session cookies, so security reports are
taken seriously.

## Reporting a vulnerability

Please report vulnerabilities privately through
[GitHub security advisories](https://github.com/andredelgado/continente-mcp/security/advisories/new)
rather than in a public issue. Include the affected version, the steps to reproduce and the
impact. Do not include real credentials, cookies or account data.

You should receive a response within a week. Fixes are released as a patch version for the
latest release.

## Supported versions

Only the latest published version receives security fixes.

## Scope

In scope: leaking credentials, cookies or account data (in output, logs or files), cart
changes the user did not request, and unsafe handling of website content.

Out of scope: the security of Continente.pt itself. Report those issues to Continente.
